# 🕹️ Resident Evil 7 Mods

[Ler em Português](#-mods-para-resident-evil-7)

## 📋 Overview

Mods, scripts, and quality-of-life adjustments for **Resident Evil 7**, primarily designed for use with REFramework and the Steam DX12 RT version of the game.

## 🧩 Available Mods

| Mod | Description | Version |
| :--- | :--- | :--- |
| `Better Flashlight` | Adjust the flashlight's brightness, range, and radius; turn it on or off at any time. This version also adds Xbox controller support: hold the **B button** for 1.5 seconds to toggle the flashlight. | 1.0 |

## 🛠️ Requirements

- Resident Evil 7 for PC.
- [REFramework](https://github.com/praydog/REFramework) **v1.5.9.1**.
- Resident Evil 7 (Steam) using the DX12 RT build.

## 📥 Installation

This repository uses the standard REFramework installation for the Steam DX12 RT version of Resident Evil 7:

1. Download REFramework **v1.5.9.1**.
2. Extract `dinput8.dll` to the game's root folder, next to the Resident Evil 7 executable.
3. Launch the game once to allow REFramework to create its folders.
4. Copy each script to the installation path specified in its file header, usually the `reframework\autorun` folder for Lua scripts.
5. Launch the game and verify that the mod is working.

## ✅ Compatibility

Compatibility may vary according to the game version, REFramework version, and other installed mods. Test each mod on a separate save when possible.

## 📋 Visão geral

Mods, scripts e ajustes de qualidade de vida para **Resident Evil 7**, desenvolvidos principalmente para uso com o REFramework e a versão Steam DX12 RT do jogo.

## 🧩 Mods disponíveis

| Mod | Descrição | Versão |
| :--- | :--- | :--- |
| `Better Flashlight` | Permite ajustar o brilho, o alcance e o raio da lanterna, além de ativá-la ou desativá-la quando quiser. Esta versão também adiciona suporte ao controle Xbox: pressione o **botão B** por 1,5 segundo para alternar a lanterna. | 1.0 |

## 🛠️ Requisitos

- Resident Evil 7 para PC.
- [REFramework](https://github.com/praydog/REFramework) **v1.5.9.1**.
- Resident Evil 7 (Steam) utilizando a versão DX12 RT.

## 📥 Instalação

Este repositório utiliza a instalação padrão do REFramework para a versão Steam DX12 RT de Resident Evil 7:

1. Baixe o REFramework **v1.5.9.1**.
2. Extraia o `dinput8.dll` para a pasta raiz do jogo, junto ao executável de Resident Evil 7.
3. Inicie o jogo uma vez para permitir que o REFramework crie suas pastas.
4. Copie cada script para o caminho especificado no cabeçalho do arquivo, geralmente a pasta `reframework\autorun` para scripts Lua.
5. Inicie o jogo e verifique se o mod está funcionando.

## ✅ Compatibilidade

A compatibilidade pode variar de acordo com a versão do jogo, a versão do REFramework e outros mods instalados. Sempre que possível, teste cada mod usando um save separado.
